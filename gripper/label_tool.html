Rule: box only the gripper head (wrist camera/flange → fingertips), never the arm. Fingers visibly apart → open; fingers together or clamped on an object → closed; gripper visible but state not decidable (occluded fingers, blur) → unknown. Fingers not visible at all → no box. Dashed = model proposal, becomes a label when you press Enter. Blue "gripper" boxes (YOLOE) only say where a gripper might be: fix the box, then press 1/2/3 — Enter refuses while one is left.
